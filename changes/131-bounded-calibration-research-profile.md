# Change 131: Bounded calibration Researcher profile

Status: Implemented as an opt-in example configuration.

The metered calibration profile binds Planner and Researcher to
`thinking_mode="disabled"`; its compatibility identity is `g0c-runtime-v2`.
Both retain the shared process-local meter, selected model, ordinary Worker,
tools and continuation path. Limits must be read from the actual selected
configuration, not inferred from a Skill or historical run.

Causal task allowance is separate from provider permits and output reservation.
The full report, exact evidence references and deterministic verifier remain
required. No fixed task graph, authority widening, allowance transfer, meter
reset or recovery grant is introduced.

This setting is a bounded configuration choice, not a demonstrated cause or
fix for prior failures. Earlier unqualified trials remain unqualified; exhausted
allowance or request budgets are not repaired by changing thinking mode.
Fixture checks do not establish real-provider quality or stable qualification.
